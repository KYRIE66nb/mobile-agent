# Mobile Agent 文档入口

更新日期：2026-09-25。本文档集是项目当前唯一的产品、设计与实现依据。

## 已确定的产品方向

Mobile Agent 是一个 Android AI 聊天软件。用户通过持续对话与 AI 交流，并让 AI 按需调用本地工具及其它能力完成任务。

- 聊天是首页与主要交互，普通问答直接回复。
- 多轮聊天支持自动上下文压缩，保留完整历史，通过摘要与近期原文延续长对话。
- 工具执行、进度、授权和结果进入同一消息流，用户可继续追问和调整。
- 聊天、模型、执行调度与功能模块解耦，新增工具通过统一接口接入。
- 所有功能随同一个 APK 交付；操作手机需要 Root，其它能力不以 Root 为前提。
- UI 采用一套布局、一套组件与三套配色，提供主题切换。
- 图标统一采用开源 Lucide，按实际引入资源保留上游许可。
