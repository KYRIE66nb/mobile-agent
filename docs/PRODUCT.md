# Mobile Agent 产品定义

更新日期：2026-09-25。状态：当前产品基线。

## 1. 产品本质

Mobile Agent 是一个手机端 AI 聊天软件。用户通过连续对话交流、提问和提出需求，AI 按需调用本地工具及其它能力处理任务，并在原对话中反馈过程和结果。

设计理念参考用户指定的 Codex、ZCode 等软件：以对话和上下文组织使用体验，让工具调用自然发生在聊天中，再针对手机触控和小屏阅读进行适配。

三个核心关系：

1. 会话承载用户与 AI 的持续交流。
2. 任务是对话中需要执行的工作，运行时负责推进和记录。
3. 功能模块提供工具，AI 根据需求选择调用。

普通聊天本身就是完整功能。用户无需创建任务表单、切换执行模式或选择某个功能页面，便可从提问自然进入文件处理、联网检索或手机操作。

## 2. 用户与产品价值

面向希望在手机上与 AI 交流、处理信息和完成实际事务的用户，包括普通移动用户和已 Root 的高级用户。

基本体验包括多轮聊天、流式回复、历史会话、附件和结果复用。用户可以先讨论方案，再说“按这个做”，执行后继续说“改一下”或“继续”。

非 Root 用户可使用所有不依赖 Root 的能力。其它能力仍可能需要网络、文件授权、账号或模型服务配置；“无需 Root”不等于无需各自必要条件。

Root 用户额外获得操作本机应用的能力。Root 不改变聊天方式，也不改变文件、网络和模型模块的职责。

## 3. 交互主线

用户发送消息后，AI 结合会话上下文：

- 可以直接回复，不强制生成计划或调用工具。
- 可以提出工具调用，由 App 找到对应模块执行，获得真实结果后继续回复。
- 可以在缺少关键信息时通过询问工具暂停并追问，在需要权限时走独立授权流程；回答问题不等于批准工具。
- 可以连续组合多个工具，过程在对话中呈现。

当用户离开 Mobile Agent 时，常驻悬浮助手以悬浮按钮、摘要卡和完整悬浮对话三种状态提供入口；用户明确开启常驻后，设备重启也会恢复空闲入口，但不会重放中断任务。完整状态可查看聊天、发送消息、授权、回答问题和切换任务；任务对话优先显示，另提供最近 5 个普通对话。未获得“显示在其他应用上层”权限时使用高优先级通知召回原对话，通知只负责提醒和返回，不提供直接批准高风险操作的快捷按钮。

同一会话可以包含多个独立或连续的任务。执行结束、停止或失败后，会话仍可继续。用户补充的消息必须被接收并在执行边界处理，不得只显示在页面上而被运行时忽略。

示例：用户说“读一下清单.txt，再打开备忘录核对，整理最终清单”。AI 先调用文件工具，再在 Root 可用且获得授权时调用设备工具，最后在对话中回复并提供文件。用户接着说“加上露营用品”，沿用已有上下文继续处理。

如果设备控制不可用，AI 说明这一步无法执行，可以继续处理已提供的文件，或让用户粘贴所需内容；不得假装已经读取另一个应用。

### 3.1 多轮上下文压缩

上下文压缩是基础聊天功能，随 M1a 交付。长对话接近当前模型的输入预算时，自动将较早内容整理为结构化摘要，保留近期原文后继续同一会话；用户也可以从会话菜单主动压缩。

- 根据实际或估算的 token 用量触发，不按固定聊天轮数截断；模型切换后重新计算预算。
- 优先保留用户目标、明确要求与纠正、已确定的结论、关键事实、任务进展、未解决问题、关键工具结果和文件引用。
- 当前用户请求、近期相关消息和未完成的工具调用链不随意摘要或拆散；必要时按需重新读取较早原文或文件。
- 压缩只改变发送给模型的上下文，不删除、覆盖或隐藏原始聊天记录与结果，用户仍可翻阅历史。
- 摘要是有损整理，不能承诺完整记住所有细节；精确引用、数字或原文不确定时查回来源，无法查回时明确说明。
- 压缩过程轻量提示，完成后继续对话。失败时保留已有可用上下文，不静默丢弃内容或发送超限请求。
- 压缩不获得任何额外工具权限，不会把旧的授权说明变成当前有效授权。

具体预算、摘要记录和恢复策略见 [技术架构](ARCHITECTURE.md#45-上下文管理与压缩)，界面反馈见 [UI 规范](DESIGN.md#34-上下文压缩反馈)。

## 4. 信息架构与 UI 风格

### 4.1 主要界面

- 首页直接进入聊天，新用户看到空白会话，已有用户可回到当前会话。
- 顶部提供历史会话入口、会话标题与新对话入口。
- 侧栏承载会话搜索、历史记录、工具管理和设置入口。
- 底部固定消息输入区，提供附件、工具范围、思考强度与模型选择；思考强度默认“关闭”，仍可选择由模型服务决定或其他等级；用户可直接在已配置模型之间切换，模型及各自的思考强度选择跨会话和重启保持一致。
- 输入区可在文本和语音之间切换。语音模式按住录音、松开转写，得到有效文本后再作为普通用户消息发送；转写失败、没有识别到内容或录音过短时不发送。悬浮按钮支持长按使用同一条快捷语音链路：松手发送到当前会话、上滑后松手取消、下滑后松手在新会话发送；短按展开与长按阈值前拖动贴边仍保持原行为。
- 设置中的“语音”分栏分别保存 OpenAI 兼容格式与科大讯飞语音听写格式，并允许在已完整配置的格式中选择当前使用项；密钥不进入聊天内容或普通日志。
- App 提供中文和英文，设置中可选择“跟随系统 / 中文 / English”。跟随系统时，系统主语言为中文则使用中文，其余语言统一回退英文；聊天、设置、悬浮助手、通知、工具说明和运行错误遵循同一选择。
- 通用设置允许用户调整单轮最大步骤，默认 99，可选范围 1–999；输入合法数值后实时保存，点按其它位置自动结束输入。新值从下一次任务开始生效，当前正在执行的任务不被中途改变。
- 中间消息流统一呈现用户消息、AI 回复、分步骤可折叠思考、工具过程和文件结果；工具确认从底部弹出。
- 文件预览、工具详情和设置是次级页面，返回后恢复原会话位置；JPG、PNG、GIF、SVG 与 HTML 产物直接在聊天页预览层打开，不依赖外部查看器。

不设置“任务 / 能力 / 我的”底部导航，不以任务看板或功能宫格作为首页。

### 4.2 统一风格与三套主题

采用简洁、留白充足、适合中英文阅读的聊天界面。用户消息使用轻量气泡，AI 回复主要直接排版在页面上；工具过程默认简短，详细信息按需展开。

三套主题均提供，布局与功能完全一致：

| 主题 | 视觉方向 |
| --- | --- |
| 留白对话 | 浅色底、深色文字、蓝色强调 |
| 深色工作台 | 深灰底、浅色文字、薄荷色强调 |
| 温暖手记 | 暖白底、深褐文字、灰绿色强调 |

主题入口为“设置 → 外观 → 主题”。提供三个固定主题和“跟随系统”；默认跟随系统，系统浅色对应留白对话，深色对应深色工作台，温暖手记由用户主动选择。

切换立即生效并持久保存，不改变当前会话、草稿、滚动位置或执行状态。具体颜色、组件和验收标准见 [UI 与主题规范](DESIGN.md)。

## 5. 功能模块与工具

功能模块通过统一接口提供工具，声明名称、用途、参数、权限、可用性和结果格式。AI 选择工具，App 运行时负责分派，模块负责实际执行。

| 能力 | 首个产品阶段 | Root 要求 |
| --- | --- | --- |
| 普通聊天、问答、改写和内容整理 | 基础功能 | 无 |
| 需求澄清与等待用户回答 | 基础工具 | 无 |
| 用户授权范围内的文件读取与结果保存 | 首批工具 | 无 |
| 网络检索与网页读取 | 首批工具 | 无 |
| 图片输入与理解 | 首批工具 | 无 |
| SVG 生成及 PNG、GIF 本地渲染 | 首批工具 | 无 |
| 识别屏幕、点击、输入、打开受支持应用 | 重要核心能力 | 必须 |
| 剪贴板、通知、深链接、音量和显示设置 | 手机系统能力 | 各自按 Android 权限 |
| 代码与工作区、服务连接器 | 后续能力 | 不以 Root 为前提，按执行环境授权 |
| 技能复用、定时或事件自动化 | 逐步交付 | 取决于所调用工具 |

“本地工具”指操作在手机上执行，模型推理可以由远端服务提供。模型位置与工具位置是独立概念。

解耦要求：

- 聊天页面不直接调用具体工具实现。
- 模型接入不绑定某个文件工具或设备服务。
- 各模块可以独立开发、测试、启用、关闭和替换。
- 组合工作由运行时编排，模块不直接调用彼此的内部实现。
- 新增普通工具通过实现接口和注册接入；可选专用结果展示须保留通用摘要。
- 单个模块故障不阻断普通聊天和不依赖该模块的操作。

模块化是同一个 App 内的职责与接口边界，首版不要求拆分 APK、独立扩展安装或公共插件市场。

## 6. Root 设备控制

设备控制与其它能力打包在同一个 APK 中，在运行时根据设备能力和授权状态决定是否可用。

- 启动时只进行无打扰检测，不主动弹出 Root 授权。
- 不能确认 Root 状态时显示“待检测”，不能把检查失败等同于“未 Root”。
- 已确认未 Root 时禁用设备控制，其它能力保持各自正常状态。
- 需要授权时，由用户在通用设置中主动启用并请求。
- 用户在通用设置中启用 Root，且设备服务可用后，AI 可调用受支持的手机操作工具。
- 权限失效或会话异常时停止相关操作，并在对话中说明原因。
- Root 工作可以在同一 APK 的独立进程执行，这不产生第二个应用。
- 虚拟屏是设备模块内部能力，不是用户开始聊天前必须选择的模式。
- 每次识别同时提供临时截图和带动作能力的节点信息；它们只供紧接着的一次 AI 决策使用，随后自动替换为失效占位符。优先按节点点击、长按和滚动，节点不可用时再回退到坐标。
- 支持连续多点轨迹和并行多指轨迹，可完成画板绘画、签名、拖拽路径和双指缩放；复杂动作仍绑定最近一次识别并设数量与时长上限。
- 支持有限时长等待文字、节点、前台应用出现或消失，避免只靠固定延时推进复杂流程。
- 已能确定目标的连续低风险步骤可作为一个批次在手机本地执行；每步都用当前节点重新定位，不复用过期节点，任一前置条件不符即停止并返回最新界面。支付、验证码、账号安全和系统授权确认不进入批量执行。

设备控制不向 AI 暴露任意 Root Shell。首版不自动操作支付、验证码或账号安全流程；普通用户可随时停止正在执行的操作。

剪贴板、通知和常用系统功能不复用 Root Shell，而是作为独立工具组按 Android 权限运行。通知使用权必须由用户在系统页面开启，验证码和账户安全通知不向 AI 暴露正文且禁止自动操作；亮度与旋转需要单独的“修改系统设置”授权。打开深链接、系统面板、分享文字或文件都使用 Android 的类型化 Intent，并保留系统选择/确认界面。

## 7. 工具状态与授权体验

工具管理显示可用、需授权、需配置、已关闭、不支持、降级或待检测，并说明原因与可执行的下一步。

输入区“工具”打开本会话的工具范围设置，允许用户缩小可调用范围。AI 无法自行开启已关闭的工具，用户取消某项授权后必须重新检查实际可用性。

授权请求以当前对话上的底部面板呈现，说明具体动作、访问范围和影响。系统级权限使用系统界面，结束后回到原会话。普通聊天和已获授权范围内的低风险操作不反复打断。

设备使用授权与具体动作的副作用分别判断。一次允许操作手机不能自动覆盖发送、删除或发布等行为。具体策略与执行边界见 [技术架构](ARCHITECTURE.md)。

## 8. 结果、记录与隐私

结果可以是普通文本、带来源的说明、文件、图片或外部操作结果。文件以回复附件卡片提供预览、分享与继续加工入口，不要求每次回复都生成产物。JPG、PNG、GIF、SVG 在应用内显示，其中 GIF 保留动画；HTML 在禁用脚本、网络请求、文件访问和链接跳转的沙箱中渲染。图像渲染使用模型给出的自包含 SVG：可以直接保存 SVG、转换透明或指定背景的 PNG，也可以把多张完整 SVG 帧按各自时长编码为循环 GIF；GIF 不解析 SVG 内的脚本、SMIL 或 CSS 动画。

用户可以继续追问、停止当前执行、重新尝试合适的步骤，并查看历史会话。未知是否成功的外部写入不得盲目重试。

只使用当前任务所需且获授权的上下文。用户能够理解哪些文件、截图或工具结果会发往模型服务；密钥和令牌不进入消息、普通日志或产物。

模型切换直接位于聊天输入区，模型连接管理、数据管理、外观和通知位于设置或相应次级入口。数据管理按模型展示服务端实际返回的输入、输出与合计 Token 用量，不把客户端估算伪装成账单数据。面向大众的正式版本应提供可用的默认模型路径；具体服务商、成本和账号方案仍待实施确定，不在首页要求用户理解 API 协议。

## 9. 首版范围与后续范围

首个完整 MVP 包含：

- 多轮聊天、流式回复、会话历史、自动/手动上下文压缩与消息恢复。
- 正式聊天 UI、三套主题、跟随系统和外观设置。
- 统一的本地工具调用与可用性管理。
- 文件、网络、图片理解，以及 SVG/PNG/GIF 本地图像渲染能力。
- Root 检测及设备控制在同一对话内的一次完整执行。
- 读取本机可启动应用列表，并通过列表返回的真实包名打开应用，不使用固定应用白名单。
- 手机操作不再为前台或后台模式单独询问。用户明确指定时直接照做；未指定时由 AI 根据任务目标判断：打开或切换应用、展示页面及需要用户看到屏幕结果的任务使用前台，能够独立完成且不应打扰当前屏幕的任务使用后台隔离屏。侧边悬浮按钮发送的语音指令遵循同一规则。离开 App 后通过三态常驻悬浮助手或持续通知查看实时文字步骤、切换最近/任务会话、回复与授权、返回原对话并立即停止。
- 进度、必要授权、停止、等待用户、错误与恢复。
- 结果预览、分享以及基础技能复用。

后续再扩展代码执行环境、更多连接器、自动化与第三方能力生态。首版不追求全机型、全应用兼容，不承诺无限后台运行或完整桌面 IDE。

## 10. 验收场景

| 场景 | 预期体验 |
| --- | --- |
| 关闭所有工具后聊天 | 正常多轮回复，没有多余计划、权限请求或设备依赖 |
| 长对话自动压缩 | 保留关键要求、最近消息与工作进展，继续原会话，原始记录仍可查看 |
| 手动压缩或切换小窗口模型 | 按当前预算重组上下文，精确细节可追溯；失败时不丢记录、不发超限请求 |
| 对话中处理附件 | AI 调用本地文件工具，真实结果回到原会话，可继续修改 |
| 联网研究 | 回复可追溯来源，必要时生成可分享文件 |
| 已 Root 手机操作 | 获得授权后调用设备工具，过程、停止与结果都在对话中 |
| 未 Root 或撤销 Root | 相关操作不可用，其它工具和普通聊天不受影响 |
| 同一会话切换主题 | 仅视觉变化，输入、附件、历史位置和执行状态保持 |
| 重启应用 | 主题选择、会话历史与执行记录恢复，不自动重放未知副作用 |
| 停止后继续聊天 | 当前执行停止派发新动作，会话仍可补充或继续 |

聊天质量以回复质量、上下文衔接、流式稳定性和用户留存衡量；工具价值以真实完成率、结果接受情况和继续使用衡量。工具调用次数与消息数量不单独代表成功。
